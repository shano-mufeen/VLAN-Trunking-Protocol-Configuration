# VTP-VLAN-Trunking-Protocol-Configuration
A hands-on Cisco Packet Tracer project demonstrating how to configure VLAN Trunking Protocol (VTP) using Cisco Catalyst 2960 switches.  This lab introduces VTP Server and Client modes, trunk links, and shows how VLANs created on a single switch are automatically propagated to all other switches in the same VTP domain.
